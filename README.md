# Automated Public Lighting

**Project Code:** PRJ_306  
**Project Domain:** Embedded Systems and IoT  
**SDG Mapping:** SDG 9 — Industry, Innovation and Infrastructure

## Overview

Automated Public Lighting is a B.Tech Computer Science and Engineering mini-project focused on improving public lighting efficiency through camera-based activity detection and zone-based lighting control.

The proposed system uses an ESP32-CAM to capture images and perform lightweight image processing for activity detection. It is designed to control three lighting zones independently using GPIO outputs. Ambient-light sensing and cloud-based monitoring are considered additional features for future integration.

## Objectives

- Explore activity-based public lighting control.
- Divide the lighting arrangement into three zones.
- Control individual LEDs based on detected activity.
- Investigate ambient-light sensing using an LDR.
- Explore cloud-based monitoring for system status and data logging.

## Technology Stack

- ESP32-CAM with OV2640 camera
- Embedded C++ and Arduino framework
- Lightweight image processing
- GPIO-based LED control
- LDR-based ambient-light sensing (planned)
- Cloud monitoring (planned)
